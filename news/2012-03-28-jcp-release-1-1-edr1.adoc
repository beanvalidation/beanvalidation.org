= Bean Validation 1.1 officially reaches the JCP
Emmanuel Bernard
:awestruct-layout: news
:awestruct-tags: [ "release" ]

Bean Validation 1.1 early draft 1 officially reaches the JCP and is available
link:http://jcp.org/aboutJava/communityprocess/edr/jsr349/index.html[on their website]. You already knew about it from the link:http://beanvalidation.org/news/2012/03/13/release-1-1-edr1/?utm_source=blog&utm_medium=web&utm_content=blogedr1&utm_campaign=1_1_edr1[release]
and link:http://beanvalidation.org/news/2012/03/16/artifacts-1-1-edr1/?utm_source=blog&utm_medium=web&utm_content=blogedr1&utm_campaign=1_1_edr1[artifacts] announcements.

That's still a significant milestone that has to be reached by the JCP rules.
A specification needs to produce a certain amount of output which is regulated
by the JCP itself. If you are curious, I encourage you to read the link:http://jcp.org/en/procedures/jcp2[process document].

Note that JSR-349 (Bean Validation 1.1) does run under the previous version of
this process but in practice we obey the rules of the current version
(especially in openness).
