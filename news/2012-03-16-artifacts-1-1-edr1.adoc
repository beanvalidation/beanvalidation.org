= Code artifacts published for Bean Validation 1.1 early draft 1
Emmanuel Bernard
:awestruct-layout: news
:awestruct-tags: [ "release" ]

Following the release of the link:http://beanvalidation.org/news/2012/03/13/release-1-1-edr1/?utm_source=blog&utm_medium=web&utm_content=blogedr1&utm_campaign=1_1_edr1[first early draft] for Bean Validation 1.1,
we have published the code artifacts:

* the code source
* the jar
* the JavaDoc

All are available on link:https://repository.jboss.org/nexus/content/groups/public/javax/validation/validation-api/1.1.0.Alpha1/[JBoss's Maven repository]. Alternatively, you can
reference them in your Maven POM:

[source,xml]
----
<dependency>
    <groupId>javax.validation</groupId>
    <artifactId>validation-api</artifactId>
    <version>1.1.0.Alpha1</version>
</dependency>
----

Enjoy.
